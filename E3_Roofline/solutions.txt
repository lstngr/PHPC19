NOTE: Class slides - Compute the  triad performance
Triad =equiv= c[i] = scalar*a[i] + b[i]
So 2 operations (flops) and 3 floats (3*8=24B). 
The AI = 2/24 = 0.083 Gflops/GB
We are below the ridge point, so the performance is given by (peak brandwidth)*(AI) and not the (peak FP perfo).
In our case, 0.083 < 2.96 so the actual performance becomes:
perf = 30GB/s * 0.083Glops/GB = 2.49 Gflops/s << 88.7Gflops/s

CONCLUSION: Memory access increases the latency of the test, and we are prevented from reaching peak performance (we would need more memory locality).
